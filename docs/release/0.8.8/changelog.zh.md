## 0.8.8 — 首个版本

用手柄驱动 EMI 的配方浏览器。

### 修复

*   EMI 的按键全部存在它自己的配置里，不注册任何 Minecraft `KeyMapping`，所以 Control Flex 的动作列表里一直没有它：**键盘能翻配方，手柄不能**。本模组注册了 22 个 Control Flex 能自行发现的伪按键，并把每次按下交给 EMI 自己的处理函数 —— 现在手柄能做键盘能做的事。

### 新增

*   **浏览** —— 查看配方与用途、收藏、物品树、配方树、后退与前进。
*   **搜索与开关** —— 聚焦搜索框、清空搜索、开关 EMI。
*   **合成** —— 合成一个或一组，进背包或到光标。
*   **创造模式** —— 刷一个或一组物品，进背包或到光标。
*   **管理** —— 隐藏物品、按 ID 隐藏、复制配方 ID。
*   **可自由重绑** —— 22 个动作统一列在 Control Flex 的按键设置里，位于 GUI 层，触发方式与层归属和内置按键完全一致。
*   **沿用 EMI 自身的规则，而非重写一套** —— 按下时走 `stackInteraction` / `genericInteraction` / `recipeInteraction`，合成、隐藏、刷物品的行为与键盘按键完全一致。不注入任何假输入，也不改写 EMI 的 `binds.*`，你的键盘设置保持原样，一次按下只触发一次。
*   **同一份源码，两个加载器** —— Forge 与 Fabric 行为一致；没有 mixin，也不修改任何类。

### 注意

*   动作作用于光标下的物品栈 —— 这是 EMI 自己的判定规则。先指到物品，再按键。
*   合成、隐藏与刷物品只对 **EMI 侧边栏**里悬停的物品栈生效。
*   当文本框获得焦点（EMI 搜索框、铁砧改名框、告示牌），或 EMI 被关闭、正在重新加载时，除「开关 EMI」外都不会触发 —— 这是 EMI 自身的行为，不是本模组的额外限制。
*   「复制配方 ID」可用于侧边栏收藏；在配方界面里 EMI 把该上下文放在私有字段中，因此该动作在那里无效。
*   `defaultStack`、`deleteCursorStack`、`showCraft` 未做桥接 —— 前两个是 EMI 配方界面内部的逻辑，第三个是「按住」状态而非一次按下。

需要 **Control Flex 0.8.8+** 与 **EMI 1.1.0+**（实测 1.1.24），Minecraft 1.20.1，Forge 或 Fabric。仅客户端。
